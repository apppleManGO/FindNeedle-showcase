# 손가락·삽날 자국

맨손으로 헤친 곳에는 손의 진행 방향을 따르는 가는 줄이, 삽으로 뜬 곳에는 긁힌 면과 휘어진 삽날 자국이 생긴다. 표면에 자국을 그리는 처리와 모래 높이를 바꾸는 처리는 별개다. 같은 단계 안에서 이동해도 자국은 남고, 모래를 덮은 범위에서는 자국이 지워진다. 걸으면 발바닥 모양 자국도 같은 레이어에 남고, 모래가 흘러내린 곳의 자국은 지워진다. [모래 질감](모래질감.md)

## 확인 방법

나란한 두 곳을 손과 삽으로 작업한 다음 한쪽에만 모래를 쏟는다. 다른 쪽 자국이 남는지 확인한다.
