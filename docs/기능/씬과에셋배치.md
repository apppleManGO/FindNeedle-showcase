# 기본 씬과 테스트 에셋 배치

기준 씬은 `SampleScene.unity`다. BeachDemoBuilder가 기본 해변·플레이어·매입소·발견물 배치를 만들고 BeachSampleDressing이 테스트 에셋 배치를 담당한다. 기본 씬 재생성은 직접 편집한 배치를 교체하므로 현재 테스트에는 저장된 씬을 열어 사용한다.

Play를 누르면 모래 표면, 양손, 대회장 전용 배구 코트와 공, 모래성 양동이 등이 초기화된다. 이 오브젝트를 점검할 때는 Play 중의 Hierarchy도 확인한다. [에셋 목록](../에셋목록.md) · [상업용 에셋 후보와 출처](../상업용에셋후보.md)

## 확인 방법

기준 씬에서 Play를 누르고 시작 지점의 양동이, 대회장의 동쪽 코트, 양손 모델을 확인한다.
