# HUD와 상황별 조작 안내

왼쪽 위에는 해변 이름, 수색 시간, 체력, 골드가 나온다. 더위는 [살갗 색과 과열 시의 시야·숨소리 변화](더위와체력.md)로 알린다. 오른쪽 위에는 가방의 종류별 수량, 장착 장비와 보유 장비가 보인다. 탐지 후에는 신호와 재사용 대기시간이 표시된다.

가운데 조준점은 발견물, 양동이, 공 등 현재 상호작용할 대상의 안내를 보여준다. 하단에는 맨손·도구·운반 상태에 맞는 조작이 표시된다. 시작, 거래, 쓰러짐, 해변 클리어 시에는 해당 화면에서 다음 행동을 선택한다. PC 기본 해상도는 1920×1080이다.

## Kenney UI Pack 적용 (2026-11-11)

HUD를 IMGUI에서 uGUI로 옮겼다. 배치 코드는 그대로 두고, [BeachCanvas.cs](../../Scripts/UI/BeachCanvas.cs)가 매 프레임 받은 사각형 목록을 캔버스 요소로 바꿔 그린다. 패널과 버튼은 [Kenney UI Pack](https://kenney.nl/assets/ui-pack)(CC0)의 이미지를 9-slice로 쓰고, 버튼을 누르면 같은 팩의 클릭음이 난다. 살 수 없는 버튼은 회색 버튼으로 바뀐다. 시작 메뉴는 왼쪽에, 해변 배경과 확대된 바늘 미리보기는 오른쪽에 배치한다. 클리어 패널은 화면 아래에 두어 그 위로 수선공이 보인다. 이미지와 임포트 설정은 `Assets/FindNeedle/UI/Resources/BeachUI`와 [BeachAssetImport.cs](../../Scripts/Editor/BeachAssetImport.cs)에 있다.

## 시작 화면 배치 (2026-11-18)

왼쪽에 제목과 **함께 찾기 · 방 만들기**, **방 참가**, **혼자 찾기**를 세로로 둔다. 아래에는 플레이 방법과 종료가 있다. 방 만들기 또는 혼자 찾기를 누르면 동료 나란히 캐릭터 선택 화면으로 이동한다. 실제 해변 캐릭터 10종을 좌우 버튼으로 바꾸고 준비 완료를 누른다. 접속한 동료의 모습과 준비 상태를 4명씩 표시하며, 인원이 많으면 다음 페이지로 넘긴다. 방장은 모두 준비하면 해변을 선택할 수 있다. 외형을 바꾸면 준비가 풀린다. 참가자는 주소 입력·접속·취소를 사용하며, 연결 후에는 방장의 해변 선택을 기다린다. 접속 상태와 오류는 오른쪽 하단에 표시한다. 시작 화면에서는 수선공을 숨기고 오른쪽에 바늘귀가 보이는 확대 바늘과 목표 안내를 표시한다. 실제 매장된 바늘의 위치는 보여주지 않는다. 수색 시작 시 기존 1인칭 시점으로 돌아간다.

## 확인 방법

동전을 줍고 매입소에서 판매한다. 가방 수량이 줄고 골드가 늘어나는지 두 패널을 함께 본다.
