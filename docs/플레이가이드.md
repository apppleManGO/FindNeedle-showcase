# FindNeedle 플레이 가이드

Unity 6000.3.10f1 · URP · PC 1인칭 싱글 플레이 프로토타입

## 실행과 첫 발견

Unity에서 `Assets/Scenes/SampleScene.unity`를 열고 Play → **동네 해수욕장**를 누른다. 시작 자리 앞쪽 조개 근처를 내려다보고, 중앙의 원을 모래에 맞춰 클릭한다. 같은 곳을 한두 번 헤쳐 동전 테두리가 드러나면 중앙 점을 맞추고 E로 줍는다. 주황색 차양 매입소에 접근해 B로 상점을 연다. 발견물의 수량·개당 매입가를 확인하고 ‘모두 판매’를 누른 뒤, 모종삽 옆 ‘구매’를 누른다.

| 조작 | 동작 |
|---|---|
| WASD / 마우스 | 바라보는 방향 기준 이동 / 고개 돌리기 |
| 왼쪽 Shift 유지 | 눈높이를 낮춰 모래와 물건 살펴보기. 이동 속도는 서 있을 때의 약 27% |
| 왼쪽 클릭 | 맨손은 가까운 모래를 조준하면 손을 뻗어 양옆으로 헤친다. 손끝이 닿은 뒤에 홈과 둔덕이 생긴다. 먼 곳은 가까이 가거나 Shift로 숙인다. 모종삽은 한 번 떠서 다른 곳을 본 뒤 다시 클릭해 쏟기 |
| 갈퀴 장착 후 왼쪽 클릭 | 서서 발 앞의 모래 표면을 넓게 훑기. 걸려 나온 큰 쓰레기는 E로 줍는다. |
| 오른쪽 클릭 | 맨손으로 두 손에 한 줌 뜨기. 옆으로 이동하거나 돌아서서 다시 우클릭하면 그 자리에 내려놓는다. |
| 마우스 휠 | 하단바에서 이전·다음 칸 선택. 첫 칸은 맨손이고 나머지 8칸은 장비와 발견물이 함께 쓴다. 같은 종류의 발견물은 한 칸에 쌓인다. |
| R | 맨손과 구입한 장비 사이를 전환한다. 한 삽을 뜬 채로 탐지기·자석 칸으로 바꿀 수 있다. |
| E | 발견물 줍기, 공 잡기, 양동이·성탑 조작. 매입소에서는 조준한 물건이 없을 때 상점 열기 |
| B | 매입소에서 상점 열기. 거래 중에는 마우스로 선택하고 닫기 또는 Esc로 탐색 재개 |
| G | 조준한 모래에 5초 동안 위치 표시. 협동 중에는 친구에게도 보인다. |
| Q | 탐지기 칸에서 사용. 삽이 비었으면 전방, 차 있으면 삽 속 검사. 재사용 3초 |
| F | 선별 자석 칸에서 현재 삽 안의 철제 물건 하나 선별 |
| T | 파라솔 칸에서 휴대용 파라솔을 조준한 모래밭에 꽂기. 다시 누르면 옮기기 |
| Esc / 다시 클릭 | 마우스 해제 / 시점 조작 재개 |

공을 든 상태에서는 좌클릭으로 던진다. 시작 위치 오른쪽의 주황색 양동이는 E로 들거나 내려놓는다. 든 채로 모래를 보고 우클릭 다섯 번, 원하는 빈 모래밭을 보고 좌클릭하면 양동이 모양의 탑을 찍고 계속 들고 있는다. 테마별 규칙과 개별 테스트 방법은 [기능별 목차](../README.md)에서 확인한다.

축제 다음 날 해변에서는 물가에 버려진 어망을 발견할 수 있다. 그물에 걸린 거북이를 가까이 보고 E로 풀어준 뒤, 남은 그물을 다시 E로 수거한다. 폐어망은 손에 들리며 해변 청소 결과에 기록된다. 수거 자루에 넣거나 일반 수거함에 넣는다.

매입소 옆에는 금속함·페트병함·일반 수거함이 따로 있다. 휠로 쓰레기를 손에 들고 가까이서 맞는 통을 조준해 **E**를 누르면 하나가 들어가고 지갑에 즉시 2 G가 더해진다. 선별 자석을 들고 금속함에 E를 누르면 보유한 철제 쓰레기를 한꺼번에 넣는다. 남은 쓰레기는 매입소에서 개당 1 G에 일괄 판매할 수 있다. 하단바가 가득 차면 기존 종류만 더 담을 수 있다.
