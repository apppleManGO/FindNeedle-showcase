# 탐지기와 자석 선별

대회장과 축제 해변에서 맨손으로 시작해 모종삽을 구매하면 다음으로 탐지기를 살 수 있다. 모종삽 장착 중 Q를 누르면 빈 삽일 때는 전방 90도·2.8 m 안의 금속 유무를 검사하고, 모래를 든 상태에서는 삽 속 물건을 검사한다. 신호를 들은 플레이어가 다음 수색 지점을 정한다. 재사용 대기는 3초다.

축제 해변의 선별 자석은 같은 장착 상태에서 F로 사용한다. 삽 속 철제 병뚜껑 또는 바늘 하나를 꺼낸다. 병뚜껑은 가방에 들어가고 바늘은 클리어로 이어진다.

## 확인 방법

같은 위치에서 빈 삽과 모래를 든 삽으로 Q를 사용해 HUD의 전방·삽 위 표시를 비교한다.
