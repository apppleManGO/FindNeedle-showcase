# 바늘을 찾은 순간

2026-11-20 추가. 바늘을 줍거나 자석으로 건지면 결과 패널이 바로 뜨지 않는다. 약 3.5초 동안 찾은 순간을 보여 준 뒤 패널이 올라온다.

## 순서

| 시간 | 화면 | 소리 |
|---|---|---|
| 0초 | 조작이 멈추고 화면 가장자리가 어두워진다. | 금속성 "팅" |
| 0.3–1.3초 | 1인칭 그대로 바늘이 손에서 화면 가운데로 올라오고, 시선이 모래에서 바다와 하늘로 올라간다. 바늘에 반짝임이 돌고 화면이 조금 당겨진다. | 반짝이는 네 음 |
| 1.3초 | 3인칭으로 바뀌어 캐릭터가 바늘을 쥔 손을 머리 위로 든다. 가까이서 시작해 결과 화면 구도까지 천천히 물러난다. 발밑에서 모래가 튄다. 위에 "바늘을 찾았다!" | 승리 음 |
| 2.5초 | 위 문구가 내려가고 가운데에 수색 시간이 크게 찍힌다. 치운 쓰레기가 있으면 "바늘 하나 찾는 동안 해변 쓰레기 N개를 치웠다"가 이어진다. | 도장 소리 |
| 2.8초 | 신기록이면 "신기록!"과 별이 찍힌다. | 도장 소리와 반짝임 |
| 3.5초 | 기존 결과 패널이 뜬다. 카메라는 마지막 구도 그대로라 화면이 튀지 않는다. | |

이 3.5초 동안은 버튼도 하단바도 나오지 않는다. 녹화한 화면을 그대로 잘라 써도 된다.

## 협동

- 바늘을 찾았다는 메시지에 찾은 사람의 번호가 함께 간다.
- 찾은 사람은 위와 같다. 나머지는 0초에 위쪽에 "방장이 바늘을 찾았다!", "친구 2가 바늘을 찾았다!"처럼 찾은 사람이 뜨고, 1.3초 동안 카메라가 찾은 사람 쪽으로 돌아간다.
- 1.3초부터는 찾은 사람의 앞에서 그 사람이 바늘을 머리 위로 든 모습을 비춘다. 팀 전원의 캐릭터가 팔을 들어 환호한다.
- 3.5초에 각자 자기 캐릭터와 결과 패널로 돌아온다.
- 느려 보이는 것은 화면 연출뿐이다. 해변의 시간과 상태는 그대로 흐르므로 PC끼리 어긋나지 않는다.

## 아직 안 된 것

- 소리는 코드로 만든 단음이다. 실제 효과음, 대회장 관중 환호, 날아오르는 갈매기는 다음 단계다.
- 찾은 사람을 비추는 화면에서 바늘은 실제보다 2.4배 크게 그렸지만, 몇 미터 떨어진 거리라 작게 보인다.
- 사람이 직접 한 확인은 없다. 화면은 배치 모드에서 찍은 사진으로만 확인했다.
