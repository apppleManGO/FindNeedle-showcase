# 비치발리볼

비치발리볼 대회장의 동쪽 경계의 네트에서 수색 구역으로 공이 날아온다. 경고음이 들리면 코트 쪽을 보자. 가까운 공을 조준하고 E를 누르면 공중에서 잡거나 바닥에서 주울 수 있다. 모래를 들고 있다면 먼저 내려놓는다. 공을 든 상태에서 좌클릭하면 보는 방향으로 던지고 기존 장비를 다시 든다. 코트에서 날아온 공에 맞으면 체력이 10 줄어든다. 바닥에 멈춘 공을 15초 동안 아무도 줍지 않으면 다시 서브한다.

## 협동 (2026-11-20)

해변에 공이 하나다. 방장 PC가 공을 움직이고 모두에게 위치를 보낸다. 동료가 공을 들면 그 사람의 몸이 두 손으로 공을 들고 있고, 내 화면에서는 잡을 수 없다. 둘이 동시에 잡으려 하면 방장에게 먼저 닿은 사람이 갖는다. 서브된 공에 맞는 사람은 방장이 정한다. 방장이 메뉴를 열어도 공은 계속 움직인다.

## 확인 방법

공을 잡고 좌클릭으로 던진 뒤 기존 장비가 다시 보이는지 확인한다.
