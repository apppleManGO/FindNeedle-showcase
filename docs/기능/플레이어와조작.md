# 1인칭 이동과 손

WASD로 이동하고 마우스로 시점을 돌린다. 왼쪽 Shift를 누르고 있는 동안 눈높이가 낮아져 발앞의 모래와 작은 물건을 가까이 볼 수 있다. Esc로 마우스를 풀고 게임 화면을 클릭하면 다시 시점을 조작한다.

모래를 받칠 때와 배구공을 안을 때는 서로 다른 양손 자세를 쓴다. 모종삽과 탐지기는 장착 상태에 따라 손에 표시된다. 맨손 헤치기는 손이 닿는 거리에서 시작하며, 멀어지거나 고개를 크게 돌리면 중단한다.

## 수선공 모델 (2026-11-11)

플레이어 몸을 [Quaternius Ultimate Modular Men](https://quaternius.com/packs/ultimatemodularcharacters.html)(CC0)의 Worker 모델로 바꿨다. 1인칭에서는 그림자만 보이고 걸을 때 걷기 동작, 서 있을 때 대기 동작을 한다. 타이틀과 클리어 화면에서는 카메라가 앞으로 돌아 나와 바다를 등진 수선공의 상반신을 패널 위에 잡는다. 클리어 때는 환호 동작을 고른다. 모델 파일이 없으면 기존 도형 캐릭터로 동작한다. 손은 기존 1인칭 손 모델을 그대로 쓴다. 같은 팩의 Beach(해변 복장) 캐릭터는 협동판 후보로 남겨 두었다.

## 수영복 캐릭터 (2026-11-16)

플레이어 몸을 Tirgames assets의 [LowPoly Beach Characters](https://assetstore.unity.com/packages/3d/characters/lowpoly-beach-characters-399742) 10명으로 바꿨다. 몸을 만들고 맞추고 움직이는 일은 [BeachBody.cs](../../Scripts/Player/BeachBody.cs)가 맡고, 내 몸([BeachWalker.cs](../../Scripts/Player/BeachWalker.cs))과 다른 플레이어의 몸([BeachGhost.cs](../../Scripts/Net/BeachGhost.cs))이 함께 쓴다.

- **누가 어떤 캐릭터인가**: 플레이어 번호로 정한다. 혼자 할 때와 방장은 0번(빨간 수영복 남성)이고, 참가자는 접속 번호에 따라 남녀가 번갈아 나온다. 같은 사람은 모든 화면에서 같은 캐릭터로 보인다. 고르는 화면은 아직 없다.
- **동작**: 대기와 걷기는 팩에 든 Humanoid 클립을 쓴다. 팩에 없는 환호(두 팔을 들고 뛰기)와 쓰러짐(뒤로 눕기)은 코드로 자세를 만든다.
- **재질**: 팩의 재질은 기본 파이프라인용이라 실행 중에 같은 텍스처로 URP 재질을 만들어 입힌다. 팩의 원본 파일은 고치지 않았다.
- **더위**: 캐릭터 전체가 재질 하나를 쓰므로 붉어질 때 수영복과 머리카락도 함께 붉어진다.
- **1인칭 손**: 기존 손 모델을 그대로 쓴다. 손을 뻗을 때 보이던 작업복 소매는 맨팔 색으로 바뀐다. 손의 피부색은 캐릭터마다 맞추지 않았다.
- **팩이 없을 때**: `Assets/TirgamesAssets`가 없으면 이전의 Worker 모델로 돌아간다. 유료 팩이라 저장소에 올리지 않아도 프로젝트가 열리고 실행된다.

코드에서 불러올 수 있게 팩의 `Prefabs` 폴더를 `Assets/TirgamesAssets/PolyWorld/Meshes/Characters/Beach/Resources/BeachSwimmers`로 옮겼다. 팩을 다시 임포트하면 원래 위치에 `Prefabs`가 새로 생기므로 같은 방식으로 옮긴다.

## 확인 방법

발앞을 헤친 뒤 반걸음 옮겨 다른 곳을 조준한다. 두 번째 접촉 위치와 손의 방향을 확인한다.

## 장비 지급과 손 모델 검증

- **요구사항** 모든 해변의 첫 방문과 재방문은 빈 가방·0골드·맨손으로 시작한다. 테마 해금은 기존 저장 기록을 따른다.
- **설계** 상점 진열대 FBX의 메시와 URP 재질을 장착 모델에도 공유한다. 기존 손잡이 위치를 기준으로 손 모델과 삽 위 모래의 위치를 맞춘다.
- **구현** 모종삽은 모든 해변에서 2 G, 탐지기는 대회장·축제 해변에서 모종삽 구매 후 7 G에 산다. 오른손에는 모종삽, 왼손에는 구매한 탐지기가 표시된다.
- **테스트** 시작 시 미보유·비장착과 잔액 부족을 확인한다. 동전 두 개와 팔찌 하나를 팔고 장비를 순서대로 구매한 뒤 맨손 전환, 재장착, 파기·쏟기와 탐색을 확인한다. 해변 재방문 때도 같은 초기 조건을 검사한다.
