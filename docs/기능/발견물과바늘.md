# 발견물 노출과 바늘 회수

물건의 윗부분이 해당 지점의 모래 표면에 닿으면 조준하고 E로 주울 수 있다. 모래를 뜰 때는 작업 전후의 표면 높이 사이에 중심이 있는 물건만 함께 담긴다. 바늘은 기본 배치에서 표면 약 5.4 cm 아래에 있다.

평지에 펼친 바늘은 끝이 잠깐 반짝이고 그 자리에 남는다. 더미 위에 쏟으면 가운데에 얕게 덮인다. 맨손으로 가운데를 헤쳐 노출한 뒤 E로 줍는다. 양동이로 만든 성탑에서는 섞여 있던 물건이 탑 옆에 떨어진다. 바늘을 줍거나 자석으로 건지면 [찾은 순간 연출](바늘찾은순간.md)이 나온 뒤 단계가 끝난다. 다른 물건은 가방에 보관한다. [매입 가격](가방과매입소.md)

## 확인 방법

바늘이 섞인 모래를 더미에 쏟아 먼저 E로 줍기를 시도한다. 가운데를 헤쳐 바늘이 드러난 뒤에만 클리어되는지 확인한다.
