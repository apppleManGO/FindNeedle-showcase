# 모래 질감 고도화

판 자국이 매끈한 그릇 모양으로 영원히 남아 찰흙처럼 느껴지던 모래를, 흘러내리고 젖고 흩날리는 모래로 바꾼다. 요구사항 분석 → 설계 → 구현 → 테스트 순서로 진행했고 이 문서가 그 기록이다.

## 1. 요구사항

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| R1 | 흘러내림 | 이웃 격자 사이 기울기가 안식각(tan 33° ≈ 0.65)을 넘으면 높은 쪽 모래가 낮은 쪽으로 옮겨 간다. 옮기는 동안 모래 총량은 변하지 않는다. 같은 자리를 거듭 파면 구덩이가 넓어진다. |
| R1-a | 기존 손맛 보존 | 평지에서 한 줌(28 cm·7.8 cm)이나 한 삽(45 cm·14 cm)을 한 번 뜬 자국은 무너지지 않는다. 첫 동전 튜토리얼의 깊이와 노출 판정이 바뀌지 않는다. |
| R1-b | 물건이 뜨지 않음 | 모래가 흘러내려 물건 아래가 비면 물건이 표면으로 내려앉는다. |
| R2 | 젖은 모래 | 파내거나 무너져 속이 드러난 곳은 어두운 색이 되고 약 45초에 걸쳐 마른다. 쏟은 모래도 잠시 어둡다. |
| R3 | 입자 | 뜰 때 알갱이가 튀고, 쏟을 때 손·삽에서 바닥으로 줄기가 떨어지고, 무너질 때 부스러기가 구른다. |
| R4 | 발자국 | 걸으면 좌우 번갈아 얕은 자국이 남는다. 발자국만으로는 평지 아래 1.4 cm보다 깊어지지 않아 묻힌 물건을 드러내지 못한다. |
| R5 | 새는 모래 | 두 손에 뜬 모래는 걷는 동안 한 걸음마다 조금씩 발밑에 떨어진다. 처음 양의 55%까지만 줄고, 떨어진 양은 바닥에 그대로 쌓인다. 삽은 새지 않는다. |
| R6 | 표면 디테일 | 손대지 않은 모래에는 바람결 무늬와 햇빛 반짝임이 있고, 파거나 젖은 곳에서는 사라진다. |
| R7 | 소리 | 발소리, 쏟는 소리, 흘러내리는 소리가 나고 매번 음높이가 조금씩 다르다. 음원 에셋을 추가하지 않는다. |
| R8 | 해상도 | 격자 한 칸을 7.8 cm에서 6.25 cm로 줄인다. 세 해변 크기와 기존 반경·깊이 수치는 그대로다. |

제약: 솔로 프로토타입의 조작·판정 수치는 유지한다. 흘러내림 계산은 작업한 주변에만 돌려 프레임 비용을 일정하게 둔다. 물가 쪽 젖은 띠는 수색 구역 밖 배경과 이음매가 생겨 이번 범위에서 뺐다.

## 2. 설계

| 구성 요소 | 역할 | 담당 요구사항 |
|---|---|---|
| `SandGrid` | Unity 오브젝트에 의존하지 않는 높이·습기 격자. 긁기, 쏟기, 발자국, 흘러내림, 마름을 계산한다. | R1, R2, R4, R8 |
| `SandPatch` | 격자를 메시와 정점 색으로 옮기고, 매 프레임 흘러내림 2회와 마름을 진행한다. 입자와 자국 레이어를 소유한다. | R1, R2, R3 |
| `SandGrains` | 알갱이 메시 파티클. 튀는 알갱이와 떨어지는 줄기를 낸다. | R3 |
| `SandTracks` + 셰이더 | 기존 자국 마스크에 발자국 붓을 더하고, 습기(정점 색)·바람결·반짝임을 그린다. | R2, R4, R6 |
| `SandAudio` | 잡음으로 발소리·쏟는 소리·흘러내리는 소리를 만든다. | R7 |
| `BeachSearch` | 걸음마다 발자국·새는 모래를 처리하고, 표면이 바뀌면 물건을 내려앉힌다. | R1-b, R4, R5 |

**흘러내림.** 긁기·쏟기가 건드린 범위를 격자가 기억한다. 한 번의 패스는 그 범위의 각 칸에서 8방향 이웃과 높이 차를 비교해, 안식각 한도를 넘는 양의 20%를 낮은 칸으로 옮긴다. 옮긴 칸이 있으면 범위를 그만큼 넓혀 다음 패스로 넘기고, 0.5 mm 넘게 옮긴 칸이 없으면 멈춘다. 가장자리 칸은 지금처럼 높이 0으로 고정한다.

**기존 손맛 보존.** 한 번 뜬 자국의 가장 가파른 기울기는 깊이 × 1.54 ÷ 반경이다. 한 줌은 0.43, 한 삽은 0.48로 한도 0.65 아래라 그대로 남고, 같은 자리를 두 번 뜨면 0.86·0.96이 되어 무너지기 시작한다.

**습기.** 칸에서 높이를 d만큼 잃으면 습기를 d ÷ 4 cm만큼 올린다(최대 1). 쏟은 자리는 중심 0.55까지 올린다. 초당 1/45씩 마른다. 습기는 정점 색으로 셰이더에 전달한다.

## 3. 테스트

| 요구사항 | 검증 방법 |
|---|---|
| R1, R1-a, R2, R4, R8 | `SandGridTests` 단위 테스트 (EditMode) |
| R1-b, R3, R5, R7 | 플레이 모드 스모크 테스트: 실제 씬에서 파기·쏟기·걷기를 실행해 예외 없음과 상태 값을 확인 |
| R2, R6 | 스모크 테스트에서 게임 카메라 화면을 저장해 눈으로 확인 |

### 테스트 결과 (2026-11-11, Unity 6000.3.10f1 배치 모드)

**단위 테스트 15개 전부 통과.** 실행: Test Runner 창의 EditMode, 또는 `Unity -batchmode -runTests -testPlatform EditMode`.

| 요구사항 | 테스트 | 확인한 내용 |
|---|---|---|
| R1 | `R1_DeepHoleSlidesWidensAndKeepsItsSand` | 한 삽을 네 번 뜬 구덩이가 무너져 넓어지고 바닥이 메워진다. 총량이 보존되고 한도를 넘는 기울기가 남지 않는다. |
| R1 | `R1_SteepMoundSpreadsOut`, `R1_BorderStaysLevelWhenSandSlidesNextToIt` | 가파른 더미가 퍼진다. 가장자리 칸은 0으로 남는다. |
| R1-a | `R1a_OneHandfulKeepsItsShape`, `R1a_OneTrowelScoopKeepsItsShape`, `R1a_TutorialCoinIsStillUncoveredByOneHandful` | 한 번 뜬 자국은 그대로다. 튜토리얼 동전은 한 줌으로 여전히 드러난다. |
| R2 | `R2_DugSandIsDampThenDries`, `R2_PouredSandLandsDamp` | 판 곳이 젖고 45초에 마른다. 쏟은 곳은 0.55로 젖는다. |
| R4 | `R4_FootprintsNeverDigBelowTheirFloor`, `R4_FootprintLeavesSandDry`, `R4_FootprintInAHoleDoesNotRaiseIt` | 50번 밟아도 1.4 cm에서 멈춘다. 밟은 곳은 젖지 않고, 구덩이 안을 밟아도 바닥이 올라오지 않는다. |
| R8 | `R8_BeachSizesStayExactAtTheFinerStep` | 10·12.5·11.25 m가 160·200·180칸으로 나누어 떨어진다. |
| 공통 | `ScrapeReturnsExactlyWhatItRemoved`, `PourAddsExactlyTheAmount`, `HeightInterpolatesBetweenCells` | 뜬 양과 쏟은 양이 정확히 맞는다. |

**플레이 모드 스모크 테스트 통과(예외·셰이더 오류 없음).** 실제 씬에서 스크립트로 조작해 얻은 값이다.

| 요구사항 | 결과 |
|---|---|
| R1 | 같은 자리를 네 줌 뜨면 중심이 -31 cm가 아니라 -22 cm에서 멈추고, 뜬 반경 밖 34 cm 지점까지 0.9 cm 내려앉았다. 네 줌 쌓은 더미는 20 cm에서 멈췄다. |
| R1-b | 공중에 뜬 발견물 없음. |
| R4 | 발자국 깊이 0.8 cm, 좌우 번갈아 찍힘. |
| R5 | 열 걸음 뒤 손의 모래가 1.640 → 0.902, 정확히 55%에서 멈췄고 안내 문구가 한 번 나왔다. |
| R2, R6 | 캡처 화면에서 구덩이 가장자리의 젖은 색, 발바닥 모양 자국, 옅은 바람결, 드문 반짝임을 확인했다. |

**확인하지 못한 것.** 정지 화면과 스크립트 조작으로만 검증했기 때문에, 알갱이가 떨어지는 움직임(R3), 흘러내리는 속도감, 소리(R7), 실제 프레임 속도는 에디터에서 직접 플레이해 봐야 한다.

**테스트 중 고친 것.** 발자국이 젖은 얼룩으로 번져 형태가 읽히지 않아, 밟은 곳은 젖지 않게 하고 자국 농도를 올렸다. 알갱이는 육면체가 눈에 띄어 크기를 절반으로 줄였다.
