# 모래성 양동이

E로 주황색 양동이를 든 뒤 모래를 조준하고 우클릭해 다섯 번 담는다. 5/5가 되면 빈 모래밭의 조준 원을 보고 좌클릭한다. 그 자리에 뒤집힌 양동이 모양의 모래탑이 남고, 빈 양동이를 그대로 든다. 섞인 발견물은 탑 옆에 나온다. E로 직접 내려놓으면 채운 횟수가 유지되며, 바닥의 양동이에도 손이나 삽으로 떠온 모래를 한 번씩 담을 수 있다.

## 확인 방법

4/5에서 찍기를 시도하고, 한 번 더 담아 플레이어 옆의 다른 지점에 찍는다. 양동이를 든 상태로 다시 우클릭해 다음 탑을 준비한다. 양동이를 내려놓은 뒤 탑을 보고 E를 누르면 모래로 돌아간다.
