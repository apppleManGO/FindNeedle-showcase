# FindNeedle 에셋 제작 목록

기준은 Unity 6000.3.10f1, URP, 1인칭 PC 데모다. 맨손과 모종삽으로 시작해 단계별로 탐지기와 선별 자석을 쓰는 세 해변을 대상으로 한다. 수량은 서로 다른 원본의 수이며 씬에서는 재사용한다.

| 우선순위 | 필요한 에셋 | 수량과 쓰임 | 현재 상태와 제작 기준 |
|---|---|---|---|
| 핵심 | 변형 모래 표면, 잔모래 재질 | 지형 메시 1, 반복 가능한 재질 1 | 기존 SandPatch 메시 유지. 낮은 카메라 각도에서 세 번 판 홈과 양옆 둔덕이 읽히도록 무늬와 노멀 강도를 낮춘다. |
| 핵심 | 수선공 캐릭터, 모자, 작업 가방 | 1인칭 양손 1세트, 협동용 전신 후보 1세트 | 기존 도형 캐릭터 사용 가능. 교체 시 가까이 보이는 손과 도구의 부착점, 조준점 가림을 확인한다. |
| 핵심 | 대기, 걷기, 맨손 헤치기, 삽질 | 동작 4종 | 기존 절차적 동작 확장. 맨손은 양팔이 바깥으로, 삽질은 삽날이 모래 쪽으로 움직여야 한다. |
| 핵심 | 모종삽, 금속탐지기, 선별 자석 | 장착 모델 각 1 | 기존 모델을 바탕으로 짧은 손잡이, 삽날, 탐지 코일을 강조한다. 양손 동시 장착 시 겹침 확인. |
| 핵심 | 바늘, 동전, 반지, 팔찌 | 매장물 모델 4종 | 기존 모델 개선. 바늘귀, 동전 테두리, 반지의 빈 중심, 팔찌 구슬이 일부만 노출돼도 구분되게 한다. |
| 핵심 | 모래 긁기, 삽질, 탐지음 | 모래·삽 각 2~3개 변형, 짧은 비프음 1개 | 반복 입력 시 소리 겹침을 줄인다. 비프 간격으로 거리 변화를 들려주고 화면 신호와 맞춘다. |
| 핵심 | 획득, 판매, 구매, 바늘 발견 피드백 | 짧은 효과음 4종, 작은 반짝임 1종 | 획득과 판매가 서로 다르게 들려야 한다. 반짝임은 물건이 드러난 뒤 사용한다. |
| 데모 마감 | 파라솔, 돗자리, 매입 가판대, 표지, 경계 말뚝·로프 | 각 1세트, 파라솔 색 변형 2~3개 | 기존 배치와 상점 상호작용 거리 유지. 캐릭터 뒤에서 매입소를 알아보기 쉽게 차양 색을 구분한다. |
| 데모 마감 | 조개, 발자국, 해안선, 파도, 먼 섬 | 조개 2~3종, 발자국 1쌍, 해안 배경 1세트 | 조개는 탐색 단서, 발자국은 동선 안내에 사용한다. 장식 밀도를 조절해 단서가 묻히지 않게 한다. |
| 데모 마감 | 파도 환경음, 모래 위 발소리 | 루프 1개, 발소리 3~4개 | 환경음 위로 탐지기의 약한 신호가 들려야 한다. 루프 연결점과 발걸음 속도를 확인한다. |
| 데모 마감 | 도구·가방·잔액 아이콘, 신호 단계, 조작 안내, 한국어 폰트 | 아이콘 약 6종, 신호 4단계, 글꼴 1종 | 기존 HUD에 적용. 작은 크기에서 판독 가능하고 시스템 글꼴이 없는 PC에서도 한글이 표시되어야 한다. |
| 확장 후보 | 자루 또는 망사 체, 붓기·흔들기 동작 | 용기 1, 동작 2종 | 모래 운반이나 체질을 채택할 때 제작한다. |
| 출시 준비 | 타이틀 로고, 대표 이미지, 플레이 스크린샷 | 로고·대표 이미지 각 1, 게임 화면 여러 장 | 실제 게임의 캐릭터, 모래 더미, 드러난 바늘을 활용해 제작한다. |

조달 우선순위는 모래 재질과 소리, 캐릭터 동작, 배경 소품 순이다. 기존 플레이가 가능한 모델은 필요한 부분부터 교체한다.

상업용 후보와 다운로드 링크는 [상업용 에셋 후보](상업용에셋후보.md)에 정리했다. 발견물 도형을 실제 모델로 바꿀 후보와 라이선스는 [도형 대체 에셋 후보](상업용에셋후보.md#도형-대체-에셋-후보--2026-11-14)에 있다.
